# AI work samples

I am Michael Bergdolt, studying for an M.Sc. in Computer Science with a focus on Data Science at
HAW Hamburg. This repository collects small, self-contained samples of my work with AI agents
and their evaluation.

| Sample | What it shows |
|---|---|
| [`agent-pipeline/`](agent-pipeline/) | A Claude Code multi-agent pipeline that takes GitHub issues from implementation through independent review to merge, with hooks, scripts and a token-cost analysis; built together with a friend. |
| [`job-market-radar/`](job-market-radar/) | A weekly, unattended monitoring agent as a Claude skill: searches job boards and career pages via MCP connectors, checks employer ratings and reports what changed since last week, with the comparisons moved into a tested script. |
| Evaluating an evolutionary prompt-optimization system (paper + notebook) | Coming soon. |

Each folder has its own README with what it is, how it is built, and its known limitations.
